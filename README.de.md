# Tennis Scores API — Beispiele

ATP- und WTA-Ergebnisse und Ranglisten: alle Spiele eines Datums oder eines ganzen Turniers (Grand Slams, Einzel, Doppel, Mixed), mit Satzständen, Tiebreaks, Setzliste, Runde, Platz und Sieger — oder die aktuellen Ranglisten.

Der Actor läuft auf **Ihrem** Apify-Konto (API-Token). Die Nutzung wird über Ihren kostenlosen oder kostenpflichtigen Plan abgerechnet. Standby/MCP ist nicht gebaut; diese Beispiele rufen nur die Apify-API auf.

## Links

## Synchronen Lauf starten

Setzen Sie `APIFY_TOKEN` auf Ihren eigenen Apify-Token. Committen Sie ihn nicht.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Beispiele in Python, JavaScript und curl liegen unter `examples/`. Autor: Public Records. Lizenz: MIT. In diesem Repository sind keine GitHub Actions aktiv.
