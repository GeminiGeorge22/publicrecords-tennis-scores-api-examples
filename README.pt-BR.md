# Tennis Scores API — exemplos

Placares, resultados e rankings ATP e WTA: todas as partidas de uma data ou de um torneio inteiro (Grand Slams, simples, duplas, mistas), com parciais, tiebreaks, cabeças de chave, rodada, quadra e vencedor — ou os rankings atuais.

O Actor roda na **sua** conta da Apify (token de API). O uso é cobrado no seu plano gratuito ou pago. Não há modo Standby/MCP; estes exemplos chamam apenas a API da Apify.

## Links
- [Página no Apify Store](https://apify.com/publicrecords/tennis-scores-api)
- [Receitas n8n / Make / Zapier / Pipedream](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates)

## Rodar um job síncrono

Defina `APIFY_TOKEN` com o seu próprio token da Apify. Não o envie no repositório.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Os exemplos em Python, JavaScript e curl estão em `examples/`. Autor: Public Records. Licença: MIT. Este repositório não tem GitHub Actions.
