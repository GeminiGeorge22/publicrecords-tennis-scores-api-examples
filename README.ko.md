# Tennis Scores API — 예제

ATP·WTA 점수, 결과, 랭킹: 날짜 또는 대회 전체(그랜드슬램, 단식, 복식, 혼합복식)의 모든 경기와 세트 점수, 타이브레이크, 시드, 라운드, 코트, 승자, 또는 현재 랭킹을 가져옵니다.

Actor는 **본인** Apify 계정(API 토큰)에서 실행됩니다. 사용 요금은 무료 또는 유료 플랜으로 청구됩니다. Standby/MCP 모드는 없습니다. 이 예제는 Apify API만 호출합니다.

## 링크
- [Apify Store 페이지](https://apify.com/publicrecords/tennis-scores-api)
- [n8n / Make / Zapier / Pipedream 레시피](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates)

## 동기 실행

`APIFY_TOKEN`에 본인 Apify 토큰을 넣으세요. 저장소에 커밋하지 마세요.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Python, JavaScript, curl 예제는 `examples/`에 있습니다. 작성자: Public Records. 라이선스: MIT. 이 저장소에는 GitHub Actions가 없습니다.
