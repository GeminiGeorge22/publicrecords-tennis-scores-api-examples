# Tennis Scores API — exemplos

Resultados e rankings ATP e WTA: todos os jogos de uma data ou de um torneio completo (Grand Slams, singulares, pares, mistos), com parciais, tie-breaks, cabeças de série, ronda, court e vencedor — ou os rankings atuais.

O Actor corre na **sua** conta da Apify (token de API). A utilização é faturada no seu plano gratuito ou pago. Não existe modo Standby/MCP; estes exemplos chamam apenas a API da Apify.

## Ligações
- [Página no Apify Store](https://apify.com/publicrecords/tennis-scores-api)
- [Receitas n8n / Make / Zapier / Pipedream](https://github.com/GeminiGeorge22/publicrecords-mcp/tree/main/templates)

## Executar um trabalho síncrono

Defina `APIFY_TOKEN` com o seu próprio token da Apify. Não o inclua no repositório.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Os exemplos em Python, JavaScript e curl estão em `examples/`. Autor: Public Records. Licença: MIT. Este repositório não tem GitHub Actions.
