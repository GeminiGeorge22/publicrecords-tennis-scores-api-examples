# Tennis Scores API — ejemplos

Marcadores, resultados y clasificaciones ATP y WTA: todos los partidos de una fecha o de un torneo completo (Grand Slams, individuales, dobles, mixtos), con parciales, tie-breaks, cabezas de serie, ronda, pista y ganador, o las clasificaciones actuales.

El Actor se ejecuta en **su** cuenta de Apify (token de API). El uso se factura en su plan gratuito o de pago. Este Actor no tiene modo Standby/MCP; estos ejemplos llaman solo a la API de Apify.

## Enlaces

## Ejecutar un trabajo síncrono

Defina `APIFY_TOKEN` con su propio token de Apify. No lo incluya en el repositorio.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Los ejemplos en Python, JavaScript y curl están en `examples/`. Autor: Public Records. Licencia: MIT. Este repositorio no tiene GitHub Actions.
