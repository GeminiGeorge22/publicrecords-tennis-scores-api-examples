# Tennis Scores API — exemples

Scores, résultats et classements ATP et WTA : tous les matchs d'une date ou d'un tournoi entier (Grands Chelems, simple, double, mixte), avec les sets, tie-breaks, têtes de série, tour, court et vainqueur — ou les classements actuels.

L'Actor s'exécute sur **votre** compte Apify (jeton API). L'usage est facturé sur votre offre gratuite ou payante. Le mode Standby/MCP n'est pas disponible ; ces exemples appellent uniquement l'API Apify.

## Liens

## Lancer un job synchrone

Définissez `APIFY_TOKEN` avec votre propre jeton Apify. Ne le commitez pas.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Les exemples Python, JavaScript et curl sont dans `examples/`. Auteur : Public Records. Licence : MIT. Ce dépôt n'a pas de GitHub Actions.
